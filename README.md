# 奶蛙：月沼远征

原创像素风 2D 横版 Roguelike 浏览器动作游戏。纯 JavaScript、Canvas 2D、Web Audio；没有 npm 依赖、远程字体或运行时素材下载。

## 游玩

- A / D 或左右方向键：移动。
- 空格 / W / 上方向键：跳跃，再按一次二段跳。
- J：三连击，支持按住持续攻击。
- K / Shift：短暂无敌冲刺。
- L：奶泡能量满 100% 后释放范围爆发。攻击和击杀补充能量。
- E：房间清场并选择祝福后，靠近右侧月门进入下一房间。
- Esc：暂停 / 返回；结算画面 R：重新开始。
- 手机横屏：使用画面底部虚拟按钮；暂停菜单可设置声音与震屏。

六个随机战斗房间，三个区域，十二种祝福，每种最多叠加三层。最后挑战潮汐蟾王：泡泡弹幕、跳砸与横扫，半血进入月潮狂涌。死亡重开清空本局能力，浏览器保留最高分、通关次数与设置。

## 本地运行

需要 Node.js 22 或更新版本。解压源码，进入此目录：

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。默认端口 4173，可通过 `PORT` 环境变量调整。也可以把 `dist/` 内容部署到任意静态站点服务器。ES Modules 需要 HTTP 服务，避免直接双击 HTML。

```powershell
npm test
node tests/playthrough.mjs
```

## 源码结构

- `dist/engine.js`：独立于 DOM 的固定步长游戏模拟、碰撞、战斗、敌人、Boss 和状态转换。
- `dist/data.js`：区域配色、敌人、祝福、可通行房间模板与种子随机数。
- `dist/art.js`：程序绘制的像素角色、动作帧、场景、视差、粒子与战斗反馈。
- `dist/input.js`：键盘、多指触控、攻击连按与输入清理。
- `dist/audio.js`：原创合成音乐与动作音效。
- `dist/app.js`、`index.html`、`style.css`：界面、存储、无障碍对话框、缩放、暂停与浏览器循环。
- `tests/`：核心规则、输入回归和正常输入驱动的完整闯关检查。

所有游戏图像均在代码中自制，不使用外部图片或第三方角色贴图；角色外观以黄色、奶白肚皮、绿色眼睛的奶蛙形象为参考。操作、受击与死亡等动作使用独立绘制的动画。

## 验证结果与边界

20 项 Node 自动检查通过。房间可通行测试覆盖 200 个种子、每个种子的六个战斗房间。正常输入策略在种子 22、123 下完整通关，未修改角色生命或攻击数值；五个策略回放均正常结束。

浏览器实测：首页、开始、移动、持续连击、击杀、受击、奶泡技能、死亡结算、重开、暂停、操作说明、声音与震屏保存；桌面 1366×900 和横屏 844×390 已做视觉检查。未发现浏览器错误日志或素材加载错误。

完整通关在自动模拟中确认；真人全程通关、实际手机多指手感和音效听感仍需人工试玩。策略回放通关用时约 202–223 秒，首次玩家 8–12 分钟为设计目标，未进行真人计时验收。

本地存储键为 `milkfrog-moonmarsh:v1`。只存储纪录与设置，不保存正在进行的一局；关闭网页或刷新会返回首页。声音在开始游戏或点击声音开关的用户手势后启用。

## 技术约定

逻辑画面 640×360，60 Hz 固定步长，最多四次模拟补帧。暂停、失焦、奖励选择时清空键盘与触控缓存。所有房间具有连续地面，平台作为额外路径，出生区域无敌人。失败的本地存储或不支持的全屏功能不会阻断游戏。

网页由 Sites 以拥有者私有访问权限发布。修改后继续使用现有 `.openai/hosting.json` 的站点标识，避免重复注册。
